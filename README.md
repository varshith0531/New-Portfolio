## ⚙️ Repository Details (Portfolio Web App)

This repository contains the source code for my interactive developer portfolio website. Here is the structure and instructions on how to run it locally:

### 📁 Directory Layout
```text
New-Portfolio/
├── public/                 # Static assets (favicons, placeholders, robots.txt)
│   ├── favicon.jpg
│   ├── placeholder.svg
│   └── robots.txt
├── src/                    # Main source code directory
│   ├── assets/             # Media and document files (Resume, profile pics)
│   ├── components/         # Reusable UI sections and components
│   │   ├── ui/             # shadcn/ui components (accordion, button, card, etc.)
│   │   ├── About.tsx       # About Me section component
│   │   ├── Contact.tsx     # Contact Form section component
│   │   ├── Experience.tsx  # Experience timeline component
│   │   ├── Footer.tsx      # Website Footer
│   │   ├── Hero.tsx        # Hero banner section
│   │   ├── Navigation.tsx  # Desktop/mobile navigation
│   │   └── Projects.tsx    # Projects showcase grid
│   ├── hooks/              # Custom React hooks (use-mobile, use-toast)
│   ├── lib/                # Utility functions and wrappers (utils.ts)
│   ├── pages/              # Main page views (Index, NotFound)
│   ├── App.css             # Main component level styling
│   ├── App.tsx             # Root Router and layout configuration
│   ├── index.css           # Global Tailwind CSS configurations
│   ├── main.tsx            # Main DOM entry point
│   └── vite-env.d.ts       # Vite-specific TS declarations
├── components.json         # shadcn UI components configurations
├── eslint.config.js        # ESLint code styling configuration
├── index.html              # Core HTML structure
├── package.json            # Dependencies and npm scripts
├── postcss.config.js       # PostCSS Tailwind CSS processor config
├── tailwind.config.ts      # Custom Tailwind styling theme definitions
├── tsconfig.json           # TypeScript configuration referencing app & node tsconfigs
├── tsconfig.app.json       # App specific TypeScript configuration
├── tsconfig.node.json      # Node/Vite tooling TypeScript configuration
└── vite.config.ts          # Vite build environment configuration
```

### 🚀 Running Locally
To spin up this portfolio project locally, make sure you have [Node.js](https://nodejs.org/) installed, and run:

```bash
# 1. Clone the repository
git clone https://github.com/varshith0531/portfolio.git

# 2. Go to the project directory
cd New-Portfolio

# 3. Install the dependencies
npm install

# 4. Start the local development server
npm run dev
```

### 📦 Building for Production
To build a highly optimized static site ready for hosting:
```bash
npm run build
```
This generates a production-ready `dist` folder containing the compiled code.
